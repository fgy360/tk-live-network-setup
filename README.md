## 设备到手后，四步跑通开播流程

专线只是半成品，环境配置做不对照样封号。流程四步：

1. **部署设备**。服务商寄来一台CPE路由器，网线连接本地宽带出口，直播手机连设备发出的Wi-Fi。设备一般已预配置，通电联网自动连接控制器，不用敲命令行。
2. **环境伪装**。直播手机语言改成目标国语言，时区调成对应时区（比如美东EST/EDT），彻底关闭GPS定位。手机里不能有抖音、微信这类国内App，最好恢复出厂设置后再用。
3. **验证IP和环境**。浏览器打开ipip.net这类IP检测网站，确认显示的国家、城市、运营商和目标市场一致；再打开TikTok刷For You页，推荐流全是目标语言的本地内容，才算伪装成功。
4. **开播测试**。正式开播前先做一场15-30分钟的私密直播，用另一台设备进直播间，看画面是否稳定在720P/1080P、60帧，观察评论延迟，测试讲解商品、发优惠券、上下架这些操作。测试数据反馈给服务商，让他们在后台优化路由策略。
